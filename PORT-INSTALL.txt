Hybrid Aquatic — неофициальный порт 1.7.4-port.4 для Minecraft 26.3 / Fabric

Требуется Minecraft Java Edition 26.3, Java 25 и Fabric Loader 0.19.5.
Установите Fabric Loader через свой лаунчер, затем скопируйте содержимое
папки mods из этого архива в папку mods отдельного профиля Minecraft.
Нужны следующие версии Hybrid Aquatic и Hybrid API:
- hybrid-aquatic-fabric-1.7.4-port.4+26.3.jar
- hybrid-api-fabric-1.1.3-port.2+26.3.jar
Не оставляйте одновременно несколько версий одного мода.
Остальные зависимости прежние.

При обновлении с port.3 замените только JAR Hybrid Aquatic; Hybrid API не изменён.
Если установлен наш патч WWOO × Hybrid Aquatic, обновите его до 1.0.1+26.3.
Старый патч 1.0.0 разрешает только HA port.3. Патч WWOO в этот архив не включён.

port.4 исправляет ключи перевода предметов-блоков и добавляет подпись Hybrid Aquatic
сразу под названием предмета. Пользовательские названия сохраняются; прочие моды
и ванильные предметы не затрагиваются. Технический ID в расширенных подсказках
(F3+H) остаётся доступен для отладки.
Также восстановлены русский перевод названий/описаний достижений и фон вкладки
из кораллового камня. Подсказки плюшевых акул и вариантов бутылки переведены.

port.3 уменьшает число поисков светящихся целей и обновлений маршрутов рыб,
исправляет конкуренцию задач за движение и сокращает временные выделения памяти
при подготовке анимаций. Постоянные пути моделей, текстур и анимаций кешируются.
Поиск светящейся цели выполняется с интервалом 10 игровых тиков (0,5 с при 20 TPS).
Численность существ и параметры генерации мира сохранены.
Исправление tempt_range из port.2 также включено.

Архив включает:
- Hybrid Aquatic 1.7.4-port.4+26.3
- Hybrid API 1.1.3-port.2+26.3
- Fabric API 0.164.0+26.3
- Fabric Language Kotlin 1.13.11+kotlin.2.3.21
- GeckoLib 5.5.7 для 26.3
- Lithostitched 2.0.6-fabric-26.3
- Trinkets Updated 4.2.1+26.3 (необязательные косметические слоты)

Это локальная тестовая сборка, не официальный релиз Hybrid Labs.
Проверены автоматическая загрузка клиента/сервера, сохранение существ,
приманка, инвентарь Argonaut, вариант бутылки, рендер и генерация траншеи.
Полный длительный игровой баланс и совместимость с другими модпаками
не проверялись. Для проверки существующего мира используйте его копию.
NeoForge и версии Minecraft, отличные от 26.3, этой сборкой не поддерживаются.

Проверки port.3: 5 серверных тестов Hybrid Aquatic, 4 Hybrid API,
оба клиентских набора успешно. Выделение памяти на позу с пятью костями:
856 → 320 байт в отдельном тесте; прирост FPS всей игры не измерялся.

Проверки port.4: названия и подписи всех 523 предметов на русском/английском,
32 активных достижения и текстура фона, полный клиентский набор и 5 серверных
тестов успешно. Пользовательские названия и расширенные подсказки сохранены.

Исходники и подробности проверки находятся в проекте hybrid-aquatic,
в файле PORTING-26.3.md. Оригинальные авторы и лицензии сохранены.
